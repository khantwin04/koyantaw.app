# koyantaw.app

The Koyantaw - ကိုယ်ရံတော် landing page and privacy policy, served by GitHub
Pages at https://koyantaw.app.

Plain static files: edit, commit, push to `main`, and Pages republishes.
Preview locally with:

    python3 -m http.server 5173

**Do not move or rename `images/brand/logo-192.png`.** Every account email
the Koyantaw server sends embeds it by URL, including ones already in
people's inboxes.
